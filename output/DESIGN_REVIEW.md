# 대표 썸네일 디자인 2차 수정

원본 ZIP과 Excel을 그대로 사용해 대표 썸네일 3개만 다시 합성했습니다. 옵션 7개는 바이트 그대로 유지했습니다. 전체 182종 제작은 실행하지 않았습니다.

저장소에 추가된 `레퍼런스 1.png`를 확인하고, 두꺼운 프레임·밀집된 상단·큰 제품 사진 구조를 반영했습니다. 레퍼런스의 회색 배경은 명시적 흰색 배경 규칙에 따라 적용하지 않았습니다.

| 품명 | 사진 높이 증가 | 사진 배치 영역 증가 | 배지의 비백색 픽셀 점유율 |
|---|---:|---:|---:|
| RL0001 | 29.1% | 66.2% | 0% |
| LL0001 | 22.6% | 50.4% | 0% |
| WM0001 | 21.9% | 47.2% | 0% |

증가율은 이미지 배치 사각형의 수치이며 실제 제품 실루엣의 픽셀 면적과는 다릅니다. 이전 크롭 외곽 여백 16px을 6px로 줄여 실제 제품도 더 크게 보입니다.

프레임: 14px → 26px, 바깥 여백 12px. 배경: #FFFFFF. 로고와 제목 간격 12px, 제목·설명 간격 약 8px, 마지막 텍스트와 제품 시작 간격 20px. 제목 52px, 설명 29px. 배지 160px와 프레임은 동일 색상. 배지는 제품을 축소하지 않고 여백에서 찾습니다. 원본 구성·개수·패키지 글씨·사진 비율을 유지합니다.

## 검증

샘플 규격·프레임 두께·흰색 배경·비율 유지·영역 최대 활용·텍스트 세로 순서·배지 색/크기/점유율·7개 옵션 원본 픽셀 보존·품명별 ZIP 바이트 일치 검증 통과. 공통 함수의 세로/가로 이미지와 긴 상품명·복수 괄호 처리도 검증했습니다. 옵션 결과물 SHA-256이 수정 전과 모두 일치합니다.

## 확인 경로

- 대표: `output/<품명>/thumbnail.png`
- 왼쪽 기존 / 오른쪽 수정: `previews/<품명>-comparison.png`
- 대표 3장 한 화면: `previews/thumbnails-overview.png`
- 옵션 포함 미리보기: `previews/all-samples-preview.png`
- 수정 전 썸네일 보존: `previews/before/<품명>.png`
- 최신 PNG와 코드 묶음: `sample-deliverables.zip`

전체 원본 자료의 누락/불일치 문제는 기존 `REPORT.md`, `analysis.json`, `errors.log`에 유지합니다. 해당 분석 보고서의 최초 샘플 디자인 설명보다 이 보고서가 현재 디자인에 우선합니다. 샘플 디자인 검수 후 전체 제작 여부를 결정하세요.
