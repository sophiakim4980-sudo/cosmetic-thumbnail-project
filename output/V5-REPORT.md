현재 상태: 로컬 제작·검수 완료, 필수 누락 및 배지 검수 보류 존재. GitHub 반영은 승인 검토 거절로 미완료.

## 엑셀 분석

- 기존 원본 182개 품명, 수정 원본 183개 품명. 기존 자동화의 확인된 분리 설정까지 적용한 과거 결과도 183개였으므로 실제 새 결과 그룹은 추가되지 않았습니다.
- 의미상 변경된 기존 품명 3개: DW0001(브랜드 파일 DW 추가), EL0001(설명 2 Types → 24/48/60p), EN0001(DN0001 행 분리). DN0001이 원본 엑셀 기준 1개 추가되었고 삭제 품명은 없습니다.
- 옵션명·옵션 이미지 참조 자체의 변경은 0개입니다. DN0001 옵션 2개는 EN0001에서 소속이 바로잡혔으며, YM0001의 옵션 파일 공란 2행이 제거되었습니다. 공란 옵션 파일 9행은 여전히 남아 있습니다.
- 지정 8개 품명의 엑셀 이미지 파일명은 동일합니다. 새 ZIP을 출처로 강제 선택하고 실제 SHA256을 이전 소스와 비교했습니다. 전체 상세 매칭·해시: `output/v5-preflight.json`.
- 수정 엑셀에 기존 확인된 정정 사항이 반영되어 있으므로 과거 행 번호 및 상품 메타데이터 override는 적용하지 않았습니다. 수동 배지 좌표 설정만 적용합니다.

## 실행 방법

```bash
python -m pip install -r automation/requirements.txt
python automation/catalog.py
python automation/validate_catalog.py
python automation/test_v5.py
python automation/test_resume.py
```

선택 재제작: `python automation/catalog.py --only BB0001 HH0001 SN0001 SN0002 SN0003 SN0004 SN0005 YM0001`.

전체 재개는 같은 명령으로 진행합니다. 현재 미완료 항목이 있어 catalog.py의 종료 코드 2는 예상 결과이며, 상태 파일에 보류 이유를 기록합니다. 검수 기준을 통과한 성공 결과만 최종 대표 썸네일로 저장합니다.

수동 배지 위치는 `automation/catalog-overrides.json`의 `badge_centers`에 `"품명": [중심X, 중심Y]`로 지정합니다. 수동 위치도 상단·여백·제품 겹침 검증을 통과해야 하며 하단 위치는 거절합니다.
